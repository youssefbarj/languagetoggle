# Course Platform

Interactive language course platform with multilingual support.

## Features

- **Dual Language Support**: English and French courses
- **Progress Preservation**: Maintains course progress when switching languages
- **Automatic Language Detection**: Detects system language automatically
- **Loading Animations**: Clean loading screen with custom animations
- **Coassemble Integration**: Uses Coassemble's native resume functionality

## Technology Stack

- Next.js 14
- React 19
- TypeScript
- Tailwind CSS
- Vercel Analytics

## Getting Started

1. Install dependencies:
   ```bash
   npm install --legacy-peer-deps
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Deployment

Ready for deployment on Vercel with GitHub integration.
